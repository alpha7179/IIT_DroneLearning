3. **고층 건물 도시**: 높이 30~100 단위
4. **저층 건물 도시**: 높이 3~8 단위
5. **간격 없는 도시**: 간격 0.0, 밀도 1.0
6. **넓은 간격 도시**: 간격 5.0
7. **혼합 파라미터 도시**: 비대칭 격자, 다양한 크기

9. **최소 크기 도시**: 1x1 격자

## 사용 방법

### Unity Editor에서 실행
```
1. Window → General → Test Runner
2. EditMode 탭 선택
3. ProceduralCityGenerator.Tests → ScenarioTests
4. "Run All" 클릭
```

### 개별 시나리오 실행
```
- 특정 시나리오만 실행하려면 해당 테스트 선택 후 "Run Selected" 클릭
- 예: Scenario_SmallDenseCity_GeneratesSuccessfully
```

### 커맨드 라인 실행
```bash
Unity.exe -runTests -batchmode \
  -projectPath "IIT_DroneLearning" \
  -testFilter "ProceduralCityGenerator.Tests.ScenarioTests" \
  -testResults "TestResults-Scenario.xml" \
  -testPlatform EditMode
```
