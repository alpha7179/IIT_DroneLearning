# CityBatchGenerator 대량 도시 생성 계획

작성일: 2026-03-15

---

## 목표

ML-Agents 학습용으로 서로 다른(또는 동일한) 파라미터의 도시를 **n × m 격자**로 한 번에 대량 생성한다.
각 도시는 기존 `CityGenerator`를 재사용하여 독립적으로 생성·배치된다.

---

## 요구사항

| # | 항목 | 설명 |
|---|---|---|
| 1 | n × m 배치 | 가로 n열, 세로 m행으로 CityGenerator 인스턴스를 격자 배치 |
| 2 | 씨드 모드 | **AllRandom** (각 도시 고유 랜덤 씨드) / **AllSame** (단 1개만 생성) / **Sequential** (baseSeed + index) |
| 3 | 간격 독립 조절 | 도시 간 가로 간격(spacingX)과 세로 간격(spacingZ)을 별도로 설정 |
| 4 | Editor 버튼 | Inspector에서 "Generate Batch" / "Clear Batch" 버튼으로 즉시 실행 |
| 5 | 자동 슬롯 크기 | 각 슬롯 크기는 `maxWidth × cellW`, `maxDepth × cellD` 기준 |
| 6 | 도시 그룹화 | 각 도시의 건물·벽·바닥을 단일 부모 GameObject 하위에 묶어 계층 정리 |

### 2. CityGenerator — 도시 그룹화 (기존 코드 수정)

현재 `cityRoot`, `wallsRoot`, `floorObject`는 씬 루트에 별도 오브젝트로 생성된다.
이를 단일 **cityGroupRoot** 하위로 통합한다.

#### 계층 구조 (수정 후)

```
CityGroup_Seed{seed}          ← cityGroupRoot  (새로 추가)
├── City_Buildings            ← cityRoot       (기존, 이름 변경 없음)
│   ├── Building_0
│   └── ...
├── CityWalls                 ← wallsRoot      (기존)
└── CityFloor                 ← floorObject    (기존)
```

#### 수정 내용 (`CityGenerator.cs`)

```csharp
// GenerateCity() 내부에서 cityRoot 생성 전에 먼저 cityGroupRoot 생성
private GameObject cityGroupRoot;

// GenerateCity():
cityGroupRoot = new GameObject($"CityGroup_Seed{usedRandomSeed}");
cityGroupRoot.transform.SetPositionAndRotation(transform.position, Quaternion.identity);

// 이후 cityRoot, wallsRoot, floorObject 생성 시 부모를 cityGroupRoot로 설정
cityRoot.transform.SetParent(cityGroupRoot.transform, true);
wallsRoot.transform.SetParent(cityGroupRoot.transform, true);      // SpawnWalls() 끝에서
floorObject.transform.SetParent(cityGroupRoot.transform, true);    // SpawnFloor() 끝에서

// ClearCity():
if (cityGroupRoot != null)
{
    DestroyImmediate(cityGroupRoot);
    cityGroupRoot = null;
}
// (cityRoot, wallsRoot, floorObject 개별 Destroy 제거)
```

### 3. `CityBatchGenerator` Inspector 파라미터

```csharp
[Header("Batch Layout")]
int   columns        = 3          // 가로 열 수 (n)
int   rows           = 3          // 세로 행 수 (m)

[Header("Spacing")]
float spacingX       = 20f        // 도시 간 가로 여백 (월드 단위)
float spacingZ       = 20f        // 도시 간 세로 여백 (월드 단위)

[Header("Seed Settings")]
BatchSeedMode seedMode = AllRandom
int   baseSeed       = 0          // AllSame: 사용할 씨드 / Sequential: 시작 씨드

[Header("City Template")]
CityGenerator cityTemplate        // 파라미터 복사 원본 (씬에 배치된 CityGenerator)
```

#### `BatchSeedMode` 열거형

```csharp
public enum BatchSeedMode
{
    AllRandom,    // 각 도시마다 시간 기반 난수 씨드 (-1 전달)
    AllSame,      // 어차피 동일하므로 1개만 생성 (columns·rows 무시)
    Sequential    // baseSeed, baseSeed+1, baseSeed+2, ... 순서대로
}
```

> **AllSame 동작:** n × m 전체가 동일 씨드 → 동일한 도시가 복제되므로
> 1개만 생성하고 `CityBatchGenerator` 위치에 배치. columns/rows는 무시.

---

### 4. 슬롯 크기 계산

각 도시 슬롯의 월드 크기는 **최대 도시 크기**를 기준으로 계산한다.

```
cellW       = (template.buildingWidth + template.buildingSpacing) * template.unitDistance
cellD       = (template.buildingDepth + template.buildingSpacing) * template.unitDistance
slotWidth   = template.maxWidth  * cellW
slotDepth   = template.maxDepth  * cellD
```

---

### 5. 배치 위치 계산

`CityBatchGenerator` GameObject 위치를 배치 격자의 **좌하단(origin)** 기준으로 한다.

```
col ∈ [0, columns-1],  row ∈ [0, rows-1]

posX = origin.x + col * (slotWidth  + spacingX)  +  slotWidth  / 2
posZ = origin.z + row * (slotDepth  + spacingZ)  +  slotDepth  / 2
posY = origin.y
```

---

### 6. 씨드 할당

| 모드 | 생성 수 | col=0, row=0 | col=1, row=0 | col=c, row=r |
|---|---|---|---|---|
| AllRandom | n × m | -1 | -1 | -1 |
| **AllSame** | **1** | baseSeed | (미생성) | (미생성) |
| Sequential | n × m | baseSeed+0 | baseSeed+1 | baseSeed+(c + r×columns) |

---

### 7. 생성 절차 (`GenerateBatch()`)

```
1. 기존 배치 정리 (ClearBatch)
2. template 파라미터 유효성 검사 (null → 경고 후 중단)
3. AllSame 모드 분기:
   ┌ AllSame:
   │  a. 빈 GameObject "City_col0_row0" 생성, batchRoot 하위
   │  b. 위치 = transform.position (origin 그대로)
   │  c. CityGenerator 추가, template 파라미터 복사, randomSeed = baseSeed
   │  d. GenerateCity() 호출
   └ AllRandom / Sequential:
      slotWidth, slotDepth 계산
      n × m 루프:
        a. 빈 GameObject "City_col{c}_row{r}" 생성, batchRoot 하위
        b. 위치 설정 (posX, posZ)
        c. CityGenerator 추가, template 파라미터 복사
        d. 씨드 모드에 따라 randomSeed 설정
        e. GenerateCity() 호출
4. batchRoot → "CityBatch_{columns}x{rows}" 로 명명
   (AllSame이면 "CityBatch_1x1_Seed{baseSeed}")
```

---

### 8. 정리 절차 (`ClearBatch()`)

```
1. batchRoot가 존재하면 DestroyImmediate(batchRoot)
   (하위의 모든 CityGroup_* 포함 자동 삭제)
2. batchRoot = null
```

그룹화 덕분에 **개별 cityRoot/wallsRoot/floorObject를 따로 추적할 필요가 없음**.

---

### 9. `CityBatchGeneratorEditor`

```
[Generate Batch]  → ClearBatch() → GenerateBatch()
[Clear Batch]     → ClearBatch()
```

파라미터 표시 순서:
- Batch Layout (columns, rows) — AllSame이면 회색 처리(비활성)
- Spacing (spacingX, spacingZ) — AllSame이면 회색 처리
- Seed Settings (seedMode, baseSeed — AllRandom이면 baseSeed 비활성)
- City Template
- (구분선)
- [Generate Batch] / [Clear Batch] 버튼

## 사용 방법 (예정)

1. 씬에 빈 GameObject 생성 → `CityBatchGenerator` 컴포넌트 추가
2. `City Template` 필드에 파라미터가 설정된 `CityGenerator` 오브젝트 연결
3. `columns`, `rows`, `spacingX`, `spacingZ`, `seedMode` 설정
4. Inspector의 **[Generate Batch]** 버튼 클릭
