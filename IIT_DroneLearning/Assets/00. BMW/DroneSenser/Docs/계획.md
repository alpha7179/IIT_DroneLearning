# DroneSensorSystem 레이어별 활성화 제어 계획

작성일: 2026-03-14

---

## 목표

Inspector 및 런타임 API에서 각 센서 레이어를 독립적으로 제어할 수 있도록 수정한다.
기본값은 전체 26개 레이 모두 활성화. 기존 동작과 완전 하위 호환.

---

## 요구사항

| 레이어 | 인덱스 | 제어 옵션 |
|---|---|---|
| 상 (Top) | 0 | ON / OFF |
| 상-중 (TopMiddle) | 1 ~ 8 | OFF / 4방위 (N·E·S·W) / 8방위 (전방위) |
| 중 (Middle) | 9 ~ 16 | OFF / 1방위 (정면 N) / 4방위 (N·E·S·W) / 8방위 (전방위) |
| 중-하 (MiddleBottom) | 17 ~ 24 | OFF / 4방위 (N·E·S·W) / 8방위 (전방위) |
| 하 (Bottom) | 25 | ON / OFF |

## 설계

### 1. 새 열거형

```csharp
// 상-중 / 중-하 레이어용
public enum DiagonalLayerMode
{
    Off      = 0,  // 레이어 전체 비활성
    Cardinal = 4,  // 4방위: N, E, S, W
    All      = 8   // 8방위: N, NE, E, SE, S, SW, W, NW
}

// 중 레이어용
public enum MiddleLayerMode
{
    Off      = 0,  // 레이어 전체 비활성
    Front    = 1,  // 1방위: 정면(N)만
    Cardinal = 4,  // 4방위: N, E, S, W
    All      = 8   // 8방위: N, NE, E, SE, S, SW, W, NW
}
```

### 2. 방위 수별 활성 레이 매핑

| 모드 | 활성 CompassDirection | 해당 레이어 내 오프셋 |
|---|---|---|
| 4방위 (Cardinal) | N(0), E(2), S(4), W(6) | 짝수 인덱스만 |
| 8방위 (All) | N~NW (0~7) | 전체 |
| 1방위 (Front) | N(0) | 오프셋 0만 |

### 3. Inspector 속성 추가 (새 Header)

```
[Header("레이어 활성화 설정")]
bool              EnableTop          = true
DiagonalLayerMode TopMiddleMode      = All(8)
MiddleLayerMode   MiddleMode         = All(8)
DiagonalLayerMode MiddleBottomMode   = All(8)
bool              EnableBottom       = true
```

### 4. 내부 메서드: `ApplySensorConfiguration()`

Inspector 속성 값을 읽어 각 `_rayConfigs[i].IsEnabled` 를 일괄 설정.
`Awake()` 에서 `InitializeRayConfigurations()` 직후 호출.

```
Top(0)        → EnableTop
TopMiddle(1~8) → TopMiddleMode → Off/Cardinal/All 에 따라 IsEnabled 결정
Middle(9~16)  → MiddleMode   → Off/Front/Cardinal/All
MiddleBottom(17~24) → MiddleBottomMode
Bottom(25)    → EnableBottom
```

### 5. 런타임 공개 API (5개 추가)

```csharp
void SetTopEnabled(bool enabled)
void SetTopMiddleMode(DiagonalLayerMode mode)
void SetMiddleMode(MiddleLayerMode mode)
void SetMiddleBottomMode(DiagonalLayerMode mode)
void SetBottomEnabled(bool enabled)
```

각 메서드는 속성 값 갱신 후 내부적으로 `ApplySensorConfiguration()` 재호출.

### 6. 편의 API (1개 추가)

```csharp
int GetActiveRayCount()  // 현재 활성 레이 개수 반환
```

## ML-Agents 관측 벡터 영향

- 관측 벡터 크기 **변경 없음 (26개 고정)**
- 비활성 레이는 기존대로 `NormalizedDistance = 0.0f` 반환
- `DroneAgent.cs` 수정 불필요
