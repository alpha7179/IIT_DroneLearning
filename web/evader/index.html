Evader Design

회피 드론이 목표 지점에 도달하면서 추격자의 시선(LOS)을 차단하는 전략을 학습하는 PPO 기반 에이전트 설계.

Owner: 이재왕 Branch: work/evader 4D Continuous Action

제어 구조

RL Policy Output (4D Continuous)
    -> (thrust_cmd, roll_rate_cmd, pitch_rate_cmd, yaw_rate_cmd)
    -> PID Controller (50Hz, World 담당)
    -> Rigidbody Force / Torque -> 실제 비행

RL 정책은 직접 모터를 제어하지 않으므로 실기체 FCU와 동일한 인터페이스로 동작합니다.

Stage 1+ / Stage 2+

Stage 1+에서는 Pursuer 실시간 위치/속도 힌트를 제거하고 구조적 기억으로 대체합니다.

관측 항목차원설명

목표 방향+거리4Stage 0과 동일
마지막 추격자 관측 위치3시야 차단 시 마지막 알려진 위치
추격자 마지막 속도3추격자 상태 기억
가시 여부1현재 LOS 여부

Stage 2+에서는 84×84 RGB 카메라(CNN 인코더)와 `is_visible_to_pursuer`를 추가합니다.

보상 함수 설계

R_total =
  + w_shaping  * (d_prev - d_now)
  + w_survival * 1
  + w_occlusion * R_los
  + w_time     * (-1)
  + [Goal Reached] +1.0
  + [Captured]     -1.0
  + [Timeout]      +0.2
  + [Crash]        -1.0

LOS 보너스 설계 주의

LOS 차단 보너스는 전환 시 1회만 지급해야 합니다. 지속 보너스는 국소 최적해를 유발합니다.

Stage 기반 커리큘럼

graph LR
    S0["Stage 0 Ray + 힌트"] -->|goal_reach >= 50%| S1["Stage 1 장애물 도입 힌트 제거"]
    S1 -->|survival >= 50%| S2["Stage 2 Self-Play RL Pursuer"]
    S2 -->|survival >= 60%| S3["Stage 3 Vision + LOS"]
    S3 --> S4["Stage 4 Domain Random Sim2Real"]

각 Stage는 이전 Stage 모델을 `--initialize-from`으로 초기화해 학습 효율을 높입니다.

C# 구현 구조

EvaderAgent.cs

`CollectObservations()`, `OnActionReceived()`, `SetPursuerVisibility()`를 통해 관측·행동·LOS 주입을 담당합니다.

EvaderReward.cs

`ComputeStepReward()` 중심으로 보상 함수 분리, Inspector 기반 계수 튜닝을 지원합니다.

학습 결과

Stage 0 학습은 Unity 환경 구성 완료 후 시작 예정이며, 수렴 그래프와 Eval 결과를 업데이트합니다.
