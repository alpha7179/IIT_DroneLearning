Pursuer Stream

Pursuer Vision

추적 드론이 정답 좌표를 직접 받지 않고, 전방 카메라 화면에서 Evader를 찾아 따라가도록 검증한 비전 기반 정책입니다.

Owner: 박재현 RGB Camera Optical Flow + LSTM

프로젝트 개요

이 파트의 목표는 Pursuer가 Evader의 실제 좌표를 외워서 따라가는 것이 아니라, 카메라에 보이는 색과 움직임을 단서로 추적하는 정책을 만드는 것입니다.

무엇을 보나요?

전방 RGB 카메라에서 Evader의 붉은색 물체 영역을 찾고, 화면 중심에서 얼마나 벗어났는지 계산합니다.

왜 필요한가요?

도심에서는 목표가 건물 뒤로 가려지므로, 실제 드론에 가까운 “보고 판단하는 추적” 구조가 필요합니다.

핵심 구현

색상 기반 탐지

Evader의 고유 색을 화면에서 찾아 중심점, 면적, 화면 중심 대비 offset을 계산합니다.

Lucas-Kanade Optical Flow

Optical Flow는 화면에서 물체가 어느 방향으로 움직이는지 추정하는 방법입니다. Pursuer는 이 값으로 Evader의 다음 움직임을 짐작합니다.

시각 기반 보상

좌표 거리를 직접 보상하지 않고, Evader를 화면에 유지하고 중심에 가깝게 잡을수록 보상을 줍니다.

LSTM Memory

짧은 가림 상황에서 직전 화면 흐름을 기억해, Evader가 순간적으로 사라져도 추적 방향을 잃지 않게 합니다.

완료 상태와 최종 정리

완료된 성과

색상 조건, spawn 설정, Optical Flow, LSTM 기억 구조를 조정해 카메라 기반 추적 흐름을 최종 시나리오에 반영했습니다.

최종 정리

비전 추적이 왜 필요한지 대중도 이해할 수 있도록 시연 장면과 설명 문구를 최종 자료에 정리합니다.
