World, Physics & Sensors

강화학습 에이전트가 실제처럼 보고, 움직이고, 반복해서 배울 수 있도록 만든 Unity 기반 훈련장입니다.

이강민 · Drone Physics 배민우 · World / Sensor Simulation Foundation

Unity 팀이 만든 것

이 프로젝트에서 Unity 팀은 단순히 배경을 만든 것이 아닙니다. AI가 훈련할 도시, 드론이 실제처럼 움직이는 물리 계층, 주변을 감지하는 센서, 학습 과정을 확인하는 관제 화면까지 전체 실험 무대를 만들었습니다.

드론의 몸과 제어

이강민은 드론이 순간이동하는 물체가 아니라 질량, 추력, 자세를 가진 비행체처럼 움직이도록 물리 기반을 구현했습니다.

AI가 배우는 환경과 감각

배민우는 도시, 센서, 카메라, 관제 시스템을 구성해 에이전트가 보고 판단할 수 있는 학습 환경을 완성했습니다.

이강민 · Drone Physics

6-DOF 물리 기반

드론이 앞뒤·좌우·상하 이동과 roll, pitch, yaw 회전을 모두 가진 비행체로 동작하도록 구성했습니다.

PID 제어

드론이 고도와 자세를 안정적으로 유지하도록, 목표값과 실제 움직임의 차이를 계속 보정하는 제어기를 만들었습니다.

Reset 안정화

반복 실험 때 이전 비행의 속도나 회전이 남지 않도록, 매 에피소드가 같은 기준 상태에서 시작되게 했습니다.

검증 가능한 테스트

단독 테스트 씬과 PlayMode 테스트를 통해 yaw 반응, 정지 시 감쇠, reset 안정성을 확인했습니다.

배민우 · World / Sensor / Rendering

도시 자동 생성

건물 밀도, 격자 크기, 높이를 바꿔 다양한 도심을 만들고, 같은 seed로 같은 도시를 재현할 수 있게 했습니다.

26방향 센서

드론 주변 360도를 Raycast로 감지해, 실제 LiDAR처럼 장애물까지의 거리를 학습 입력으로 제공했습니다.

RGB / Depth 카메라

드론 1인칭 화면과 깊이 영상을 함께 만들어, 거리 숫자뿐 아니라 시각 정보도 활용할 수 있게 했습니다.

관제와 공유 API

여러 드론의 시점을 한 화면에서 보고, 최단 경로·시야 확인·스폰 위치 같은 공통 기능을 팀이 함께 쓰도록 만들었습니다.
